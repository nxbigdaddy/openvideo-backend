# 短视频AI系统安全合规与审计设计

## 1. 安全目标
- 保护模型密钥、用户数据、业务内容与系统可用性。
- 实现“最小权限、全链路审计、可追责、可恢复”。

## 2. 认证与授权
- 认证：JWT + Refresh Token。
- 授权：RBAC（SystemAdmin / WorkspaceAdmin / Editor / Viewer）。
- 权限粒度：
  - 工作区级：成员、模板、配置、预算。
  - 资源级：项目、故事、分镜、提示词（读/写/发布/删除）。

## 3. 密钥与敏感信息管理
- `api_key` 仅入库密文，采用AES-GCM加密。
- 前端读取仅返回掩码形式（`sk-****abcd`）。
- 密钥轮换策略：
  - 支持版本化密钥记录
  - 轮换后新任务用新密钥，旧任务保留可追溯元数据

## 4. 数据分级
- P0（高度敏感）：API密钥、密码Hash、密钥材料。
- P1（敏感）：用户个人信息、审计详情、错误上下文。
- P2（业务数据）：故事内容、分镜、提示词、账单。
- 不同分级应用不同访问与导出策略。

## 5. 审计日志规范
- 必记操作：
  - 登录、登出、权限变更
  - 模型配置新增/修改/删除
  - 模板发布、版本回滚
  - 任务重跑、任务取消、预算解锁
- 审计字段：
  - `operator_user_id`, `workspace_id`, `action`, `target_type`, `target_id`
  - `before_json`, `after_json`, `ip`, `user_agent`, `trace_id`

## 6. 内容安全
- 输入安全：标题与批量文本先做敏感词与合规预检。
- 输出安全：故事、分镜、提示词生成后做分类：
  - pass：自动通过
  - review：人工审核
  - reject：拦截并记录

## 7. 攻击面与防护
- Prompt注入：系统Prompt隔离、变量白名单、响应Schema校验。
- 越权访问：统一租户守卫 + 资源归属校验。
- 爆破与滥用：登录限速、接口限流、预算阈值。
- 重放攻击：Idempotency-Key + 时间窗签名（可选）。

## 8. 合规与留存
- 日志留存周期建议：
  - 审计日志：180天+
  - 运行日志：30天+
  - 账单记录：1年+
- 数据删除策略：
  - 软删除业务数据
  - 依法律法规支持导出与删除申请流程

## 9. 事件响应
- 安全事件等级：SEV1~SEV3。
- 响应流程：
  1) 告警触发
  2) 自动隔离（可疑Token/可疑IP）
  3) 人工复核
  4) 修复与复盘
  5) 审计归档
